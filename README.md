# Bench

A concept study for shop-floor build execution software: one traveler, two
surfaces. Runs, measures itself, and the surfaces talk to each other.

```bash
npm install
npm run dev      # http://localhost:3000
npm run guard    # design-system precommit check
```

Open `/floor` in a narrow window and `/plan` beside it. Run the kit check and
watch the shortage land on the planner board live.

Not affiliated with any company; all part numbers, torque values and work
orders are invented. See `CLAUDE.md` for the design contract.
